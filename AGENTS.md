# ContextMeter: rules for any agent or person working in this repo

ContextMeter is made and owned by **Liav Tal** (Wonderful). It is the same pill for Claude Code (this folder) and Codex (`codex/`).

## You may
- Run it, and fix small things for your own setup (a path, a changed log field, a key shortcut), on a **branch** with a **pull request**.

## You must never
- **Rename it.** The name stays **ContextMeter** everywhere.
- **Remove or change the credit** "Developed by Liav.T".
- **Redesign or rewrite it.** No new look, no re-skin, no building a different product from its code or design.
- Publish it or share it outside Wonderful.
- Push to `main`. Liav Tal reviews and merges every change.

## Ping Liav before merging
Slack **Liav Tal** (liav.t@wonderful.ai) with two lines on what and why, if the change touches how the pill looks or moves, Replace or auto-replace behaviour, or adds or removes a feature. Small compatibility fixes can go ahead, but tell Liav after.

After any change: run `./build.sh`, look at the pill on screen, and update `README.md` if behaviour changed.
